# SSH Games - решение от KYSS

SSH Games — это многопользовательская игра для терминала, в которой игроки подключаются по SSH и попадают в общий ASCII/ANSI-мир. Проект задуман как ответ на ТЗ про игру, работающую прямо в SSH-сессии на «голом» терминале без графической оболочки.

В текущей реализации сервер поднимает **SSH-хаб** на порту `2222`. После подключения пользователь попадает в меню выбора игры и лобби. Хаб умеет создавать отдельные игровые комнаты в виде Docker-контейнеров и проксирует пользователя внутрь выбранной комнаты по SSH.

## Что есть в проекте

Проект состоит из четырёх основных сервисов:

- **hub** — центральная точка входа по SSH;
- **snake** — общая многопользовательская змейка;
- **pingpong** — пинг-понг в терминале;
- **finalsentence** — соревновательная игра на скорость печати.

## Как это работает

### 1. Точка входа — SSH Hub
Пользователь подключается к общему SSH-серверу на порту `2222`.

После входа hub:
- принимает SSH-сессию;
- определяет ник игрока по имени пользователя SSH;
- показывает терминальное меню;
- даёт выбрать игру;
- показывает список доступных лобби;
- при необходимости создаёт новое лобби как **отдельный Docker-контейнер**;
- проксирует игрока в выбранную игровую комнату по внутреннему SSH-соединению.

### 2. Игровые комнаты
Каждая комната запускается как отдельный контейнер со своей SSH-игрой внутри.

Это даёт:
- изоляцию комнат друг от друга;
- возможность масштабировать комнаты по мере появления новых игроков;
- независимый жизненный цикл игровых сессий;
- соответствие требованию ТЗ про отдельный контейнер на комнату.

### 3. Общий мир в реальном времени
Игры не являются пошаговыми. У каждой игры есть свой внутренний игровой цикл (`tick loop`), который регулярно обновляет состояние и отрисовывает кадры всем подключённым игрокам.

За счёт этого игроки видят:
- изменения в реальном времени;
- общий игровой мир;
- одновременные действия других участников.

### 4. Рендеринг
Вся графика рисуется прямо в терминале:
- через ASCII/ANSI;
- с использованием alternate screen;
- без GUI и без браузера;
- с поддержкой PTY-режима.

## Игры и ключевые моменты

### Snake
- Общая карта для нескольких игроков одновременно.
- До 6 игроков в одном лобби.
- У каждого игрока своя змейка и свой цвет.
- После проигрыша можно возродиться и продолжить игру.

### Ping Pong
- Терминальный пинг-понг с общим полем.
- Формат: `1v1`, а если второго игрока нет — одна из сторон управляется ботом.
- Зрители тоже могут подключаться к комнате.

### Final Sentence
- Соревновательная игра на скорость набора текста.
- Раунд длится 60 секунд.
- Игроки печатают строки на скорость и точность.
- Ошибки временно блокируют ввод, поэтому важна не только скорость, но и аккуратность.

## Ключевые архитектурные моменты

- **Один входной SSH-хаб** для всех пользователей.
- **Динамическое создание комнат** через Docker API.
- **Каждая игровая комната — отдельный контейнер**.
- **Изолированная SSH-сессия** для каждого игрока.
- **Общий игровой мир в реальном времени** внутри каждой комнаты.
- **Манифест запуска** через `docker compose`.
- **Сетевое взаимодействие контейнеров** через общую Docker-сеть `games-net`.
- **Автоочистка пустых лобби**, если в комнате никого не осталось.

## Инструкция по запуску

Ниже — минимальная инструкция запуска именно в том порядке, который нужен для проекта.

### 1. Склонировать репозиторий
```bash
git clone <URL_репозитория>
cd KyssAezaSsh2
```

### 2. Открыть порт `2222`
Нужно открыть входящий TCP-порт `2222`, потому что именно на нём слушает SSH-хаб.

### 3. Скачать и установить Docker
Убедитесь, что Docker и Docker Compose доступны в системе.

### 4. Собрать контейнеры
```bash
make docker-build
```

### 5. Поднять проект
```bash
make docker-up
```

После этого хаб будет доступен по SSH на порту `2222`.

## Как подключиться к игре

После запуска можно подключиться обычным SSH-клиентом:

```bash
ssh <имя_игрока>@<хост> -p 2222
```

Примеры:
```bash
ssh denis@localhost -p 2222
ssh player1@server.example.com -p 2222
```

После подключения:
- откроется SSH Hub;
- появится меню выбора игры;
- можно выбрать существующее лобби или создать новое;
- дальше игрок будет автоматически подключён внутрь игровой комнаты.
